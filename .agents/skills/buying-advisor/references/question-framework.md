# Question Framework

Use this reference to choose category-specific clarification questions. Ask only
questions whose answers can materially change the recommendation.

## Universal purchase questions

Ask these unless already answered:

- Where will the user buy it: country/region, preferred stores, shipping limits.
- Budget: target price, absolute ceiling, currency, new vs used/refurbished.
- Primary use: main job, frequency, environment, user skill level.
- Hard constraints: dimensions, compatibility, standards, ecosystem, space,
  installation, power, connectivity, platform, delivery deadline.
- Priorities: ask the user to choose or rank 2-3 category tradeoffs.
- Dealbreakers: brands, subscriptions, materials, noise, weight, maintenance,
  warranty, repairability, privacy, return policy.

## Category prompts

Electronics and computers:
- Existing devices/OS/ecosystem.
- Required ports, standards, software, performance workload.
- Battery life, screen, size/weight, fan noise, repairability, warranty.
- For PCs: CPU/GPU/RAM/storage needs, games/apps, monitor resolution.

Phones, tablets, wearables:
- Platform preference, camera needs, battery expectations, storage size.
- Carrier/eSIM/region compatibility, update policy, size preference.
- Existing accessories or watch/earbud ecosystem.

Audio, photo, and video:
- Use environment, source devices, latency needs, codec/support requirements.
- Sound/profile preference or image/video use case.
- Portability, noise cancellation, microphone, battery, mounting, lighting.

Home appliances:
- Available space and exact dimensions.
- Household size, usage frequency, noise sensitivity, energy cost.
- Installation type, water/gas/electrical constraints, service availability.

Tools and workshop gear:
- Material and task type, duty cycle, precision, power source.
- Existing battery platform, safety gear, dust/noise constraints.
- Consumables, warranty, service, replacement parts.

Sports, outdoor, and travel:
- Body measurements or load requirements when relevant.
- Environment, season, distance/duration, weather resistance.
- Weight, packability, durability, safety certifications, return policy.

Furniture and ergonomics:
- Body measurements, room dimensions, adjustability needs.
- Material preference, cleaning, assembly, warranty, return/trial policy.
- For chairs/desks: work duration, posture issues, monitor/input setup.

Vehicles, bikes, and mobility:
- Rider/driver size, route type, terrain, storage/parking, local rules.
- Range, payload, service access, safety certifications, accessories.
- New vs used risk tolerance and inspection requirements.

Baby, child, medical, and safety-sensitive items:
- Age/weight/height or clinical/safety requirements.
- Required certifications and local legal requirements.
- Do not optimize only for price; ask about risk tolerance and professional
  guidance when appropriate.

Gifts:
- Recipient profile, existing preferences, occasion, return/exchange ability.
- Budget and whether practical, premium, playful, or safe choice is preferred.

## When to stop asking

Stop the interview when:

- The user's hard constraints are enough to eliminate bad candidates.
- The remaining uncertainty affects only minor preferences.
- Additional questions would be about taste rather than purchase risk.

Then state any assumptions and proceed to research.
