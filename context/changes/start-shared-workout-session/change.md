## Notes

Roadmap S-03: Trainer can start one active workout session for a trainee and assigned set.

Planning scope expanded on 2026-06-17:
- trainer-led shared sessions still start from the trainer's trainee detail view;
- trainees can also self-start an active session from an assigned workout set;
- trainer-led sessions show trainees a limited read-only live view from `apps/mobile/design/LiftMate.html`;
- trainee self-start sessions show trainees the full editable live view, and the trainer can later see the active status and join.
